## 各画面の実装方針

### ユーザ画面(自アカウント) / ユーザ画面(他アカウント)
ユーザーのプロフィールを表示します。自分のアカウントの場合は編集ボタンを表示し、他アカウントの場合はDMボタンを表示します。同じビューで条件分岐させることも可能です。

### トップ画面
サイトのメイン画面です。検索フォーム（フリーワード、都道府県、市区町村、利用時間帯、料金、面積）、地図検索エリア、いいねした土地一覧、おすすめリスティングを表示します。HomeControllerを作成し、ルートは`/`に設定します。

### 自己保持土地一覧画面
ログインユーザーが所有する土地の一覧を表示します。LandControllerのmyLandsメソッドで実装します。

### 土地貸出画面
自分の土地へのレンタル申請一覧を表示し、承認/拒否ボタンを設置します。RentalControllerで実装します。

### 貸出中詳細画面
現在貸し出し中の土地の詳細情報を表示します。借り手情報、期間、ステータスを表示します。
