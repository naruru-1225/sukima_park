# トップ画面の作成フロー

このドキュメントでは、トップ画面がどのように作られたかを詳しく説明します。
初めてLaravelを触る人が、画面作成の流れを理解できるように書いています。

---

## 画面作成の全体像

Laravelで画面を作るには、以下の3つのファイルを作成・編集します。

```
1. コントローラ（処理を書く場所）
   ↓
2. ルート（URLと処理を紐付ける）
   ↓
3. ビュー（HTMLを書く場所）
```

この順番で作業するのが基本です。

---

## ステップ1: 何を作るか確認する

まず、トップ画面に何が必要かを確認します。

### 参考にしたファイル

`context/画面レイアウト/home_screen.html` を開いて、モックアップを確認しました。

### トップ画面に必要な要素

1. **ヒーローセクション**: キャッチコピーとサービス説明
2. **検索フォーム**: 土地を検索するためのフォーム
   - フリーワード検索
   - 都道府県選択
   - 市区町村入力
   - 料金上限
   - 面積下限
3. **地図検索エリア**: 「地図から検索する」ボタン
4. **おすすめリスティング**: おすすめの土地一覧

---

## ステップ2: コントローラを作成する

### コントローラとは？

コントローラは「処理を書く場所」です。
ユーザーがURLにアクセスしたとき、何をするかを決めます。

### 作成手順

1. ターミナルで以下のコマンドを実行します：
   ```bash
   docker compose exec app php artisan make:controller HomeController
   ```

2. このコマンドで `app/Http/Controllers/HomeController.php` が作成されます。

3. ファイルを開いて、`index` メソッドを追加します。
   - このメソッドは「トップ画面を表示する処理」を担当します。
   - データベースから「おすすめの土地」を取得します。
   - 取得したデータをビューに渡します。

### ポイント

- メソッド名は自由ですが、一覧表示は `index` が一般的です
- `Land::latest()->take(6)->get()` で最新6件の土地を取得しています
- `return view('home', compact('recommendedLands'))` でビューにデータを渡しています

---

## ステップ3: ルートを設定する

### ルートとは？

ルートは「URLと処理を紐付ける設定」です。
「このURLにアクセスしたら、このコントローラのこのメソッドを実行する」と決めます。

### 作成手順

1. `routes/web.php` を開きます。

2. 以下のような設定を追加します：
   - URL `/`（トップページ）にアクセスしたら
   - `HomeController` の `index` メソッドを実行する

### ポイント

- `->name('home')` でルートに名前をつけると、後でリンクを作るときに便利です
- 例: `route('home')` で `/` のURLを取得できます

---

## ステップ4: ビューを作成する

### ビューとは？

ビューは「HTMLを書く場所」です。
ユーザーが実際に見る画面のデザインを作ります。

### 作成手順

1. `resources/views/home.blade.php` を新規作成します。

2. 共通レイアウトを継承します：
   - `@extends('layouts.app')` を最初に書きます
   - これでヘッダー、フッター、CSSが自動的に適用されます

3. タイトルを設定します：
   - `@section('title', 'スキマパーク')` でページタイトルを設定

4. コンテンツを書きます：
   - `@section('content')` と `@endsection` の間にHTMLを書きます

### ビューの構成

```
@extends('layouts.app')  ← 共通レイアウトを使う

@section('title', 'ページタイトル')  ← ブラウザのタブに表示される

@section('content')
    ← ここにページの内容を書く
@endsection

@push('styles')
    ← このページ専用のCSSを書く（任意）
@endpush
```

---

## ステップ5: モックアップを参考にHTMLを書く

### やったこと

1. `context/画面レイアウト/home_screen.html` を開きます
2. 必要な部分をコピーして、Blade形式に書き換えます

### Bladeへの書き換えポイント

| HTMLモック | Blade |
|-----------|-------|
| 固定のリンク `href="page.html"` | `href="{{ url('/path') }}"` |
| 固定のデータ | `{{ $変数名 }}` でPHPの変数を表示 |
| 繰り返し | `@foreach` と `@endforeach` でループ |
| 条件分岐 | `@if` と `@endif` で表示を切り替え |

### 具体例

**モックのHTML（固定データ）:**
```html
<h3>おすすめの土地タイトル</h3>
<p>東京都渋谷区</p>
<div>月額 50,000円</div>
```

**Blade（動的データ）:**
- 変数 `$land->TITLE` を使って土地タイトルを表示
- 変数 `$land->CITY` を使って市区町村を表示
- `number_format()` で金額をカンマ区切りに

---

## ステップ6: 動作確認

### 確認手順

1. Dockerコンテナが起動していることを確認
   ```bash
   docker compose up -d
   ```

2. ブラウザで `http://localhost` を開く

3. トップ画面が表示されれば成功！

### うまくいかないとき

| 症状 | 原因と対策 |
|------|-----------|
| 画面が真っ白 | PHPのエラー → `storage/logs/laravel.log` を確認 |
| 404 Not Found | ルートの設定ミス → `routes/web.php` を確認 |
| 500 Internal Error | コントローラのエラー → エラーメッセージを確認 |
| スタイルが崩れる | CSSのパスが間違っている → `@push('styles')` を確認 |

## ファイル一覧

今回作成・編集したファイル：

| ファイル | 役割 |
|---------|------|
| `app/Http/Controllers/HomeController.php` | トップ画面の処理 |
| `routes/web.php` | URLとコントローラの紐付け |
| `resources/views/home.blade.php` | トップ画面のHTML |

---

## まとめ

トップ画面の作成フロー：

1. **モックを確認** → 何を作るか把握する
2. **コントローラ作成** → 処理を書く
3. **ルート設定** → URLを決める
4. **ビュー作成** → HTMLを書く
5. **動作確認** → ブラウザで確認

この流れは他の画面でも同じです。
自分の担当画面を作るときも、この順番で進めてください。
