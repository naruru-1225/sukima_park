# F 野村さん 実装ガイド（管理者機能）

## 担当画面

| 画面名 | ブランチ名 |
|------|----------|
| ユーザ一覧画面 | feature/nomura-user-list |
| ユーザ詳細画面 | feature/nomura-user-detail |
| 問い合わせ一覧画面 | feature/nomura-contact-list |
| 問い合わせ詳細画面 | feature/nomura-contact-detail |

---

## 各画面の実装方針

### ユーザ一覧画面
登録ユーザーの一覧を表示します。Admin/UserControllerを作成し、検索・フィルター機能を実装します。ユーザーID、名前、メール、ステータスをテーブル形式で表示します。

### ユーザ詳細画面
ユーザーの詳細情報と管理操作を表示します。ユーザー情報、所有土地一覧、取引履歴を表示し、アカウント凍結/解除ボタンを設置します。

### 問い合わせ一覧画面
ユーザーからの問い合わせ一覧を表示します。Admin/ContactControllerを作成し、CONTACT_TABLEから取得します。未対応/対応済みのフィルター機能を実装します。

### 問い合わせ詳細画面
問い合わせの詳細と返信機能を表示します。問い合わせ内容、返信履歴を表示し、返信フォームを設置してREPLY_TABLEに保存します。

---

## 注意事項

管理者機能は`App\Http\Controllers\Admin`名前空間に作成します。管理者のみアクセス可能にするため、ミドルウェアでの権限チェックが必要です。

---

## 作業の流れ

1. mainブランチからfeatureブランチを作成
2. Admin名前空間のコントローラ作成・ルート設定
3. ビュー作成（context/画面レイアウトのHTMLモックを参考に）
4. コミット・プッシュしてPR作成
